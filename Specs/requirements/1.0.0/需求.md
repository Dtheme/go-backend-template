## 功能列表

### F-1.0.0-001 创建笔记

**做什么**

调用方提交标题和正文，服务生成唯一 ID 并保存到内存，返回完整笔记。

**接口与数据**

| 方法 | 路径 | 用途 | 鉴权 |
| --- | --- | --- | --- |
| POST | /v1/notes | 创建笔记 | 无 |

请求：

```json
{"title": "买菜", "content": "鸡蛋、牛奶"}
```

响应（成功，`201 Created`）：

```json
{"id": "n_9f1c2a7b3e4d", "title": "买菜", "content": "鸡蛋、牛奶", "created_at": "2026-09-07T02:00:00Z"}
```

错误情况：

| 场景 | HTTP 状态码 | error.code |
| --- | --- | --- |
| 请求体不是合法 JSON，或含未定义字段 | 400 | invalid_argument |
| title 缺失、为空白，或超过 100 个字符 | 400 | invalid_argument |
| content 超过 2000 个字符 | 400 | invalid_argument |
| 请求体超过 16 KiB | 400 | invalid_argument |

**业务规则与边界**

- `title` 必填，去掉首尾空白后长度 1 到 100 个字符（按 Unicode 字符计数，不按字节）
- `content` 可选，最长 2000 个字符；缺省为空字符串
- `id` 由服务生成，形如 `n_` 加 12 个小写十六进制字符，同一进程内不重复
- `created_at` 为服务端 UTC 时间，RFC 3339
- 并发创建互不影响，不得丢失或覆盖
- 字符长度限制的错误信息要指明字段名（如 `title must be 1-100 characters`）

**验收标准**

- [ ] AC-1 合法请求返回 201，响应含 `id`、`title`、`content`、`created_at` 四个字段，`id` 匹配 `^n_[0-9a-f]{12}$`
- [ ] AC-2 缺少 `title`、`title` 为空白、`title` 为 101 个字符时均返回 400 `invalid_argument`，`error.message` 含 `title`
- [ ] AC-3 `content` 为 2001 个字符时返回 400 `invalid_argument`，`error.message` 含 `content`
- [ ] AC-4 非法 JSON 与未知字段返回 400 `invalid_argument`
- [ ] AC-5 100 个并发创建请求全部成功且 ID 各不相同（`make test-race` 通过）

### F-1.0.0-002 读取笔记

**做什么**

按 ID 读取一条笔记。

**接口与数据**

| 方法 | 路径 | 用途 | 鉴权 |
| --- | --- | --- | --- |
| GET | /v1/notes/{id} | 读取笔记 | 无 |

响应（成功，`200 OK`）：

```json
{"id": "n_9f1c2a7b3e4d", "title": "买菜", "content": "鸡蛋、牛奶", "created_at": "2026-09-07T02:00:00Z"}
```

错误情况：

| 场景 | HTTP 状态码 | error.code |
| --- | --- | --- |
| ID 不存在 | 404 | not_found |

**业务规则与边界**

- ID 区分大小写，按精确匹配查找
- 未定义的方法（如 `DELETE /v1/notes/{id}`）返回 405

**验收标准**

- [ ] AC-1 创建后用返回的 `id` 读取，得到 200 与相同内容
- [ ] AC-2 不存在的 ID 返回 404 `not_found`
- [ ] AC-3 `DELETE /v1/notes/{id}` 返回 405

## 数据变更

无（内存存储，无迁移）。

## 非功能需求

- 性能：单机内存操作，无额外要求
- 安全：无鉴权；不记录笔记正文到日志
- 兼容：只新增接口，不改动已有接口

## 验证方式

`make run` 后用 Postman 集合（`api/postman/`，新增创建与读取两个请求）或 curl：先 `POST /v1/notes`，再用返回的 `id` `GET /v1/notes/{id}`，并验证一次 404 与一次 400。
